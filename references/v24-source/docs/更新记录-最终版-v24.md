## 一、设置页：彻底清空数据

### 功能说明
设置页新增真正生效的「清空数据」能力。点击后系统会清除以下全部用户数据，并同步清空浏览器 localStorage（若已开启云端同步，会同时把空状态推送到后端）：

- 账号信息（`state.accounts`）
- 备忘录（`state.memos`）
- 待办事项（`state.todos`）
- 提醒事项（`state.reminders`）
- 选题素材（`state.topics`）
- 数据指标（`state.metrics`）
- 个人资料（`profile`）重置为默认值
- 通知与同步开关保留（不影响系统级配置）

清空后，所有模块回到空状态，账号面板显示「还没有账号，点右上角『＋ 新建』添加第一个账号」的引导。

### 操作路径
顶部 ⚙ 设置 → 数据 → **清空数据** → 二次确认 → 一键清空。

![设置页-清空数据](docs/screenshots/v24-final/06-settings-clear.png)

## 二、账号卡片：编辑 + 删除

### 功能说明
账号面板中的每张卡片均可点击进入编辑模式，支持修改该账号的全部数据项：

- 账号名称
- 平台（含自定义平台名）
- 图标 Emoji
- 状态（活跃 / 孵化中 / 休眠）
- 目标
- **密码**（v20 新增，选填）
- **备注**（v20 新增，选填）

编辑弹窗会完整回填当前卡片数据，保存时按 `id` 更新原记录，不会新增重复卡片。弹窗底部提供「🗑 删除此账号」按钮；卡片右上角也提供常显的 🗑 删除图标，便于快速删除。

删除账号会级联清除该账号下的所有关联数据：备忘录、待办、提醒、选题、数据指标。删除后卡片从面板即时移除。

### 操作路径
1. 进入「多账号面板」；
2. 点击任意账号卡片（或右上角 ✎ 图标）→ 弹出「编辑账号」弹窗；
3. 修改字段后点「保存」；
4. 点 🗑 删除 → 二次确认 → 级联删除。

![多账号面板](docs/screenshots/v24-final/01-dashboard.png)

![账号编辑弹窗](docs/screenshots/v24-final/02-account-edit.png)

## 四、模块内卡片批量删除

### 功能说明
进入任意含卡片的模块后，工具栏右侧会出现「批量」按钮。点击后进入批量管理模式：

- 每张卡片左上角显示复选框，可自由多选；
- 卡片原有的单条编辑 / 删除入口自动隐藏，避免误触；
- 工具栏显示「已选 N 项」+「取消」+「删除」；
- 点「删除」后弹出浏览器原生确认框，列出选中数量，确认后一键删除；
- 删除账号卡片时仍会级联清除该账号下所有关联数据；
- 切换模块或视图时自动退出批量模式。

### 适用模块
多账号面板、备忘录、待办事项、提醒事项、选题素材库。

### 操作路径
1. 进入任意模块（如备忘录）；
2. 点右上角「批量」；
3. 勾选要删除的卡片；
4. 点「删除」→ 二次确认 → 批量删除。

![备忘录-批量选择](docs/screenshots/v24-final/04-batch-select.png)

![备忘录-删除后结果](docs/screenshots/v24-final/05-batch-after-delete.png)
